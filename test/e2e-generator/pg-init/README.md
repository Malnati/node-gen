# Postgres E2E init

O init do Postgres E2E é feito por `init-postgres.js` no serviço e2e (descoberta dinâmica por `connection.postgres.json` e DDL em `projects/<name>/db/`). Este diretório não contém mais scripts de init (o script anterior foi removido).
