## 5. Regras da Mudança

### Regras Funcionais
1. Cada projeto deve ser processado em paralelo (não sequencial)
2. Para cada projeto: API e MFE são gerados em paralelo
3. API container sobe antes do MFE container
4. Testes são executados após ambos os containers estarem prontos
5. Bancos de dados devem ser inicializados antes de qualquer geração

### Regras de Organização
- Manter compatibilidade com alvos existentes do Makefile
- Usar同样的padrão de nomenclatura (e2e-\<tipo\>-\<projeto\>)
- Scripts E2E devem ser idempotentes
