# Changelog — E2E: loops com timeout 1,5 s e foco nos quatro bancos

**Data/Hora (UTC):** 2026-02-19 00:02:00

## Arquivos modificados

- `test/e2e-generator/run.js` — Loops de verificação com timeout máximo 1,5 s: `POLL_INTERVAL_MS = 1500`, `HEALTH_REQUEST_TIMEOUT_MS = 1500`; cada tentativa de porta com `socket.setTimeout(POLL_INTERVAL_MS)`; health com `waitForHealth(port, N)` em tentativas de 1,5 s até 200.
- `.docker/entrypoint.e2e.sh` — Default `E2E_DB_TYPES=sqlite,postgres,mysql,sqlserver`; intervalo entre checagens de Postgres/MySQL/SQL Server reduzido para `sleep 1.5`.

## Regras/requisitos atendidos

- Testes Via Docker (make e2e, make e2e-build, make e2e-run) com foco em MySQL, SQLServer, Postgres e SQLite para todos os projetos e2e.
- Verificação de conclusão de processos em loops com timeout de no máximo 1,5 segundos por tentativa.
- Aplicações geradas: compilação obrigatória, subida da API, verificação de porta, logs e curl ao endpoint de saúde.
