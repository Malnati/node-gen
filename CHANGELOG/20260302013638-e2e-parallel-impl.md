# Changelog: Execução Paralela de E2E com API e MFE

- Adicionado alvo `e2e-api-<project>` para executar E2E de API por projeto

## Comandos Disponíveis

```bash
# Geração isolada
make gen GEN_PROJECT=test/e2e-generator/projects/accounts GEN_OUTPUT=output/accounts
make gen PROJECT=accounts OUTPUT=output/accounts
make gen-mfe GEN_PROJECT=test/e2e-generator/projects/accounts GEN_OUTPUT=output/accounts-mfe

# Bancos de dados
make e2e-dbs       # Inicia bancos de dados
make e2e-clean     # Remove containers e volumes E2E

# E2E API (apenas NestJS)
make e2e-api                    # Todos os projetos
make e2e-api-accounts          # Projeto específico
make e2e-build                  # Build da imagem E2E

# E2E MFE (apenas micro-frontends)
make e2e-mfe                    # Todos os projetos
make e2e-mfe-accounts          # Projeto específico

# E2E Completo (API + MFE em paralelo)
make e2e                       # Todos os projetos (padrão)
make e2e-all                   # Todos os projetos
make e2e-all-accounts          # Projeto específico
```

---

## Variáveis de Ambiente

- `E2E_MODE` - Modo de execução (api, mfe, all)
- `E2E_PROJECTS` - Lista de projetos (separados por espaço)
- `E2E_PARALLEL` - Número de jobs paralelos (padrão: número de CPUs)
- `GEN_PROJECT` - Projeto para geração isolada
- `GEN_OUTPUT` - Diretório de saída para geração isolada
- `PROJECT` - Alias para GEN_PROJECT
- `OUTPUT` - Alias para GEN_OUTPUT
